## Handoffs

**People.** A new joiner → you create the user, give the role(s), copy the set-password link and send it → planning or the office admin adds them to the site teams.

**Leavers.** You deactivate the user: every session ends at once.

## Common mistakes

- A set-password link works once and lasts 7 days. Making a new link stops the old one.
- Users cannot be deleted, only deactivated.
- A client role cannot be combined with admin, margin or finance rights: "Client users cannot have: ...".

## Quick card

The things you do every day:

1. Create users and send their set-password links.
2. Unlock and reset people who are locked out.
3. Deactivate leavers the same day.
4. Check that the backups ran.
5. Look at the audit log and the security page.
6. Have the roles report signed again when roles change.
