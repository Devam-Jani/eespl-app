Free labels that people pick on records, kept per module: **Material**, **Petty spend**,
**Work order** and **Issue**. Each module has its own tags. Every change is written to the audit
log.

**On the page**
- **Material**, **Petty spend**, **Work order**, **Issue** (tabs): the module whose tags are shown.
- **⤓ Export Excel**: downloads the tags of the open module as an Excel file.
- **New … tag** (field): type the new tag's name (for example "New material tag").
- **Add tag**: adds it to the open module.
- **Show archived**: tick it to also see archived tags (shown faded).
- A tag's name: click it to rename it. A box asks "Rename tag".
- **⌫** (Archive): archives the tag. It stays on old records but is no longer offered.
- **↺** (Restore): shown on an archived tag; brings it back.
- **×** (Delete): asks "Delete the tag "<name>"?" and deletes it.

**Rules**
- A name must be unique within its module (capitals do not count). Up to 100 characters.
- Prefer **⌫** over **×** for a tag that has been used.

**What happens next**
- The tag is offered at once in the forms of that module.

**Hands off**
- Receives: requests for new tags from stores, accounts and site teams.
- Passes on: the tag lists used in their forms.

**When it goes wrong**
- "This tag already exists in that module": the name is taken. Use the existing tag or choose another name.
